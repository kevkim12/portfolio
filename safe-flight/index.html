App Case Study

Safe Flight Application

A travel safety web application that scores destinations using real-time event, weather, advisory, and risk data.

Category Application
Stack React, Flask, MongoDB
Focus Risk scoring, OAuth, API integrations

Overview

A compact risk signal dashboard for travel decisions.

The project combines destination risk inputs, account handling, and authentication into a single web application for evaluating travel safety.

01

Destination Scoring

Scores destinations based on real-time weather, crime, conflict, and political risk signals.

02

API Integrations

Uses Airlabs and Travel Advisory data to support destination safety assessments.

03

Accounts

Stores user accounts and preferences with MongoDB-backed application data.

04

Authentication

Integrates Google Cloud Identity/OAuth for secure account access.

Build Notes

Implementation Details

  • Developed a web application using React.js and Flask that assesses the safety of destinations based on real-time events.
  • Integrated Airlabs and Travel Advisory APIs to score destinations based on weather, crime, conflicts, and political risk.
  • Implemented a user account system with MongoDB for storing accounts and preferences.
  • Integrated Google Cloud Identity/OAuth for secure authentication.
