Safe Flight Application

A travel safety web application that scores destinations using real-time event, weather, advisory, and risk data.

Stack React, Flask, MongoDB
Focus Risk scoring, OAuth, API integrations

Full Project Points

Build Notes

  • Developed a web application using React.js and Flask that assesses the safety of destinations based on real-time events.
  • Integrated Airlabs and Travel Advisory APIs to score destinations based on weather, crime, conflicts, and political risk.
  • Implemented a user account system with MongoDB for storing accounts and preferences.
  • Integrated Google Cloud Identity/OAuth for secure authentication.
