# Kevin Kim Portfolio

A modern static portfolio site for Kevin Kim's software engineering career.

Open `index.html` directly in a browser. No build step or generated image assets are required.

## Customize

- Update project descriptions in `index.html`.
- Update the contact email in `index.html` if it changes.
- Replace `assets/logo-placeholder.svg` with real company logo assets when ready.
- Adjust colors and layout tokens in `styles.css`.
