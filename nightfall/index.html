Nightfall Video Game

A round-based zombie shooter built with Lua and Rojo, focused on scalable gameplay systems, NPC behavior, pathfinding, and server-side security.

Full Project Points

Build Notes

  • Developed a round-based zombie shooter using Lua and the Rojo framework to support scalable game development.
  • Built six distinct zombie NPC classes with complex behaviors, creating dynamic and unpredictable gameplay challenges.
  • Engineered a dynamic zombie NPC targeting system using decision trees, priority scoring, and pathfinding.
  • Implemented a secure store system with server-side validation and hardened remote events to prevent exploits and unauthorized access to content.
