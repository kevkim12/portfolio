PhotoShare

A Flask photo-sharing application for creating albums, uploading photos, tagging images, commenting, liking photos, adding friends, and discovering content through search, leaderboards, and recommendations.

Stack Python, Flask, Jinja, SQL
Data Flask-MySQL, PyMySQL, SQLite demo mode

Build Notes

What It Does

  • Supports account registration, login, albums, photo uploads, captions, and tags.
  • Includes public browsing, photo likes, comment threads, tag search, and comment search.
  • Adds friend lists, friend recommendations, and photo recommendations based on tag overlap.
  • Provides contributor and popular-tag leaderboards for discovery across PhotoShare.
  • Uses Flask templates, reusable photo-card layouts, responsive CSS, and SQLite local demo mode.
